# Wand-method
Plataforma de consultoria fitness online WAND METHOD — Gestão de alunos, treinos e acompanhamento personalizado.

## Desenvolvimento

Use Node.js 22 e execute `node --test tests/*.test.mjs` na raiz. O aplicativo é estático e a suíte padrão usa o próprio Node.js.

Consulte o [guia do Codex Cloud](docs/desenvolvimento-codex-cloud.md) para configuração, testes, fluxo pelo celular e publicação. As orientações de projeto ficam no [AGENTS.md](AGENTS.md).
